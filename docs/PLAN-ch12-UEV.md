## 四、🔴 本章的落地难点

### 4.1 相对可落地

| 模块 | 理由 |
|---|---|
| 分子制造 | 可映射为高精度加工链（微观层面用机器代称） |
| 大规模制造 | ✅ 规模化生产是 GTCEu 核心玩法 |
| 能源缓存 | ✅ 储能是真实工业需求 |
| 超高阶控制 | 🟡 可用高级自动化替代 |
| 轨道工厂集群 | 🟡 去掉「轨道」后即「多厂区集群」，可落地 |

### 4.2 完全无支撑

| 模块 | 缺什么 | 能否自研 |
|---|---|---|
| 采能卫星 / 戴森云骨架 / 恒星能量汇集 | 天体尺度集能 | ❌ **缺游戏机制** |
| 自动货船 | 自动载具 | ❌ **缺游戏机制** |
| 行星级调度 | 星球尺度调度 | ❌ **缺游戏机制** |
| 批量恒星采能 | 恒星资源获取 | ❌ **缺游戏机制** |
| 星际基建 | 星际建设 | ❌ **缺游戏机制** |

> 🔴 **6 / 20 模块缺游戏机制。**

### 4.3 戴森云是全包最难的主题

「戴森云」涉及：天体尺度结构、恒星能量收集、长期工程维护。
**即使自研也需要新增维度 + 天体 + 巨量多方块 + 能量系统**，
工作量按整包计，不是一个章节的内容周期能容纳的。

> ⚠️ 建议：戴森云相关模块（02/03/05/12/13/15，共 6 个）统一改为
> **「超大规模能源采集」** 主题 —— 保留「采能」内核，去掉天体尺度。
