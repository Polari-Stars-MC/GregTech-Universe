## 五、本章特色：`energy` 目标的**主战场**

20 模块中 **9 个以电力为核心**：

```
蓄电 · 电机 · 基础机壳 · 基础机器组 · 电解
初级矿物电气化 · 基础控制 · 电网稳定 · 低压产能
```

> 🔴 ch01 裁剪后 `energy` 需求很少，**本章才是 `energy` 目标的首次大规模验证**。
>
> **关键设计问题**：FTB Quests 无原生能量目标，需自研，
> 且要同时适配 **GTCEu EU** 与 **Create 应力** 两套体系。
> 适配层设计错误 → 本章 9 个模块集体返工。
> **`F-06`（energy 目标）必须单独排期，优先于本章任何内容周期。**

### LV 特有的能量语义

| 语义 | 检测什么 | 难度 |
|---|---|---|
| 存量 | 玩家背包 / 机器内 EU 总量 | 🟢 需事件监听 |
| 通量 | 某机器正在耗电 | 🟡 需轮询或 hook |
| 电网 | 玩家自建电网在线机器数 | 🔴 需跨维度聚合 |
| 应力 | Create 应力网容量 / 使用率 | 🔴 需 Create API 适配 |

> ⚠️ 四者工作量差异很大。`G3-01` 必须先定，否则 `D1` 无法开工。
